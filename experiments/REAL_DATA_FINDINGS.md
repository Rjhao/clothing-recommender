# 真实数据实验发现（2026-07-07）

## 数据
- 来源：Amazon eCommerce 2019-Nov ~ 2020-Apr，6 个月真实数据
- 处理：流式过滤 fashion 类目，purchase+cart 强信号，跨月去重，k-core（用户≥3、商品≥2）
- 规模：**64,097 用户 / 21,683 商品 / 273,464 交互**（12× 旧合成版的 5,294 用户）
- 密度：0.0197%（旧合成 0.16%）

## 实验结果

### 探针 M3 (3 epoch)
- **HR@10 = 0.5673**, NDCG@10 = 0.3919
- 论文目标 0.561 — **超过 0.006**
- val loss 持续下降无过拟合（1.97→1.15→0.80→0.65...）

### 基线（CPU 端，sampled-100 LOO）
| 基线 | HR@10 | NDCG@10 | 备注 |
|---|---|---|---|
| Popular | 0.5966 | 0.4105 | 流行度基线 |
| ItemCF | 0.9527 | 0.7483 | 余弦物品共现 |
| UserCF (top-100) | 0.9995 | 0.9212 | 余弦用户共现 |
| **M3 (3ep)** | **0.5673** | 0.3919 | 完整模型 |

### 决定性 sanity check
把 test 换成 val、排除集换成仅 train，UserCF/ItemCF 仍 > 0.95 — 排除评估泄漏嫌疑。

## 诚实结论

1. **达到论文 0.561 目标**（M3 0.5673）。
2. **但被基线吊打** — ItemCF 0.95+、UserCF 0.999+、Popular 0.60 都超过 M3。
3. **真实 purchase+cart 数据有极强物品/用户共现信号** — 简单余弦 + 邻居匹配直接利用了"同用户买同品"模式。
4. **M3 引入 KG/GAT/对比学习反而引入噪声** — 复杂模型在该数据上学不到比"相似用户买过"更好的信号。
5. **与合成数据结论一致** — 之前合成数据上 UserCF 0.5022 也打赢所有学习模型（但当时是 popularity 偏置）。真实数据上是真实协同模式。

## 建议
- 论文章节如实报告：KG-HybridRec 在真实 purchase 数据上未超过经典 CF 基线。
- M3 在合成数据上 0.42 vs 真实数据 0.57 — 真实数据**确实**有更多结构可学，但**简单基线已经把这些结构用尽了**。
- 后续可探索：多模态（图像/文本）补足简单基线捕捉不到的信号，或换更稀疏的 view-only 数据。
